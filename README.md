# Criptografía

Este repositorio documenta mi proceso de aprendizaje y resolución de desafíos de criptografía y seguridad informática a través de la plataforma [CryptoHack Challenges](https://cryptohack.org/challenges).

## Estructura del Repositorio

El contenido y las resoluciones de los desafíos se encuentran organizados por ramas temáticas según las categorías de la plataforma:

- **[`general`](https://github.com/EloSanz/criptografia/tree/general):** Desafíos introductorios y fundamentales:
  - **Encoding:** ASCII, Hex, Base64, Bytes & Big Integers, Encoding Challenge (sockets/automatización).
  - **XOR:** Fundamentos bit a bit, propiedades algebraicas, fuerza bruta de un solo byte, análisis de clave repetida (*Known-Plaintext Attack*) y análisis visual de reutilización de claves de flujo (*Lemur XOR*).
  - **Mathematics:** Máximo Común Divisor (Algoritmo de Euclides), Algoritmo Extendido de Euclides, Aritmética Modular, Pequeño Teorema de Fermat e Inverso Modular.
  - **Data Formats & TLS:** Claves PEM (PKCS#1), Certificados X.509 en formato DER, Claves públicas OpenSSH (RFC 4253) y Certificate Transparency (CT logs).
